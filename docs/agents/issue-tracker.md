# Agent Issue Tracker

## Tracker Type

Local markdown.

## Purpose

Use local markdown files for planning, product audits, PRDs, specs, and implementation breakdowns while the project direction is still being shaped.

This keeps early thinking visible in the repo without creating public GitHub Issues for ideas that may change.

## Convention

- Store local planning issues under `.scratch/<topic>/` when a skill needs issue-like files.
- Keep each issue/task independently understandable.
- Include status labels from `docs/agents/triage-labels.md` when useful.
- Link back to relevant project docs, specs, or source files.

## When To Switch To GitHub Issues

Switch to GitHub Issues when the product direction is stable enough that tasks are suitable for portfolio-visible project tracking.
