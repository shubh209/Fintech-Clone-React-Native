# Camel Case Source Filenames

Source filenames will use camelCase, including React component files. Examples include `cryptoMarketScreen.tsx`, `cryptoAssetDetailScreen.tsx`, `customHeader.tsx`, `formatEuroPrice.ts`, and `normalizeTickerPoints.ts`.

This deliberately prioritizes one simple naming rule over the common React convention of PascalCase component filenames. Exported React component names should still use PascalCase in code.
